# MediaAtlas documentation

MediaAtlas is an abstraction layer over files, built for workflows.

> The filesystem tells you where a file is.
> The file itself tells you what it is.
> MediaAtlas tells you what it means.

## Status labels

Every feature in these docs is one of:

- **Implemented**: it works and is tested
- **Planned**: decided, on the roadmap
- **Idea**: brainstorming, no commitment

If a doc and the code disagree, the code is right; please fix the doc.
